# CS-300-Data-Structures-and-Algorithms
CS 300 covering data structures, algorithms, and C++ programming

1. What was the problem you were solving in the projects for this course?
The problem I was trying to solve was how to make it easier for ABCU's academic advisors to access course information and help students plan their schedules. The program needed to organize course information so that advisors could find specific courses and identify the prerequisites students would need to complete. Another part of the problem was determining which data structure would handle this information most efficiently.

2. How did you approach the problem? Consider why data structures are important to understand.
I approached the problem by comparing vectors, hash tables, and binary search trees to understand how each one stores and retrieves information. I looked at their runtime and memory requirements to determine which would be the most appropriate for the program. I learned that understanding data structures is important because the way information is stored can affect how efficiently a program performs certain operations.

3. How did you overcome any roadblocks you encountered while going through the activities or project?
A challenge that I encountered was figuring out how to implement the different data structures correctly, particularly when working with the binary search tree. I worked through these problems by reviewing my code, testing individual functions, and then making adjustments when something wasn't working as expected. Testing the program helped me identify errors and verify that the course information was being processed correctly.

4. How has your work on this project expanded your approach to designing software and developing programs?
Working on these projects has helped me understand that designing a program involves a lot more than just getting it to work. I have a better understanding of why it's important to consider how data will be organized and accessed before beginning the development. Comparing the different data structures also helped me see how design decisions can affect a program's performance.

5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
These projects have helped me become more aware of how I organize my code and structure individual functions. I've learned that separating tasks into functions makes it easier to identify problems and make changes without affecting the rest of the program. I also have a better understanding of how choosing an appropriate data structure can make a program easier to maintain and adapt as its requirements change.
